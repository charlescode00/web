# 新金進五金行 網站

臺北市大同區重慶北路三段293之1號，經營六十年的老字號五金行。單頁網站，給附近居民和第一次找上門的人用手機看：
這家店賣什麼、在哪裡、怎麼打電話。

## 設計概念：一張放大的手開收據

| 元素 | 在頁面上是什麼 |
| --- | --- |
| 鉛字黑（Noto Serif TC 特粗） | 印在收據抬頭的店名 |
| 印刷紅 | 格線、欄位名稱、「經營六十年」店章、底部兩顆印章按鈕 |
| 原子筆藍（霞鶩文楷） | 手寫填上去的內容：地址、電話、品名 |
| 牛皮紙 | 頁面底色 |
| 白邊相片＋紙膠帶 | 店家拍的照片，像貼在收據上 |

易讀性規格（由 `tools/check.js` 把關）：內文 ≥ 20px；地址、電話、商品類別 ≥ 28px；
文字對比 ≥ 7:1；可按元件 ≥ 56px 高；文字不壓在花紋或照片上。

## 檔案

- `index.html`：成品（字體已內嵌），由原始檔產生，**不要直接改**
- `index.src.html`：原始檔，改內容改這裡（要改的地方有「★」）
- `images/`：網頁用照片（已裁切、壓縮、去除 EXIF）
- `tools/build.js`：產生成品（把頁面用到的字從字體裡切出來、嵌進去）
- `tools/check.js`：自我檢查＋截圖
- `tools/photos.py`：從店家原始照片產生 `images/`（原始照片不放進版本庫）
- `tools/subset_fonts.py`：`build.js` 用的字體工具

## 改內容的流程

```bash
node tools/build.js
```

```bash
node tools/check.js 截圖資料夾
```

字體只內嵌「頁面上有用到的字」，所以改了文字一定要重跑 `build.js`，否則新字會掉回系統字體。
需要 Node＋Playwright、Python 3＋`fonttools`＋`brotli`＋`Pillow`；字體原檔第一次執行時會自動從 npm 下載。

上線只需要 `index.html` 和 `images/` 兩樣。
