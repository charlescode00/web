# 新金進五金行 網站

單頁網站。成品是根目錄的 `index.html`：只有一個檔案，樣式、程式、字體都在裡面，
不連任何外部資源，放到任何網頁空間就能用。

## 設計概念：一張放大的手開收據

| 元素 | 在頁面上是什麼 |
| --- | --- |
| 鉛字黑（Noto Serif TC 特粗） | 印在收據抬頭的店名 |
| 印刷紅 | 格線、欄位名稱、「經營六十年」店章、底部兩顆印章按鈕 |
| 原子筆藍（霞鶩文楷） | 手寫填上去的內容：賣什麼、地址、時間、電話 |
| 牛皮紙 | 頁面底色、貨架插畫的底 |
| 黃色標價籤 | 還沒拿到資料的地方，一律貼「待補」 |

易讀性規格（由 `tools/check.js` 把關）：內文 ≥ 20px；電話、地址、營業時間 ≥ 28px；
文字對比 ≥ 7:1；可按元件 ≥ 56px 高；文字不壓在花紋上。

## 檔案

- `index.html`：成品，由原始檔產生，**不要直接改**
- `src/index.html`：原始檔，改內容改這裡（要改的地方有「★」）
- `tools/build.js`：產生成品（把頁面用到的字從字體裡切出來、嵌進去）
- `tools/check.js`：自我檢查＋截圖
- `tools/subset_fonts.py`：`build.js` 用的字體工具

## 改內容的流程

```bash
node tools/build.js
```

```bash
node tools/check.js 截圖資料夾
```

字體只內嵌「頁面上有用到的字」，所以改了文字一定要重跑 `build.js`，否則新字會掉回系統字體。
需要 Node＋Playwright、Python 3＋`fonttools`＋`brotli`；字體原檔第一次執行時會自動從 npm 下載。

## 還沒拿到的資料（頁面上標「待補」）

- **營業時間**：填法寫在 `src/index.html` 的「★ 營業時間」註解。填好後，
  上方「現在」那一欄會自動顯示營業中／休息中／今日公休，JSON-LD 也要補上。
- **主要品項**：換掉「品名」表格的最後一列。
